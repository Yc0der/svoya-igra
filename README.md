# Своя игра

«Своя игра» для живой компании: экран на телевизоре и телефоны вместо кнопок, без
выделенного ведущего. Подробности — в [спеке](docs/superpowers/specs/2026-08-03-svoya-igra-design.md).

Для кого: компания 3–6 человек в одной комнате.

## Установка

```
pnpm install
```

## Запуск

```
pnpm --filter server dev
pnpm --filter client dev
```
