# Кот в мешке — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать механику «кот в мешке» (Веха 4): открывший вопрос-«кот» обязан отдать
его другому онлайн-участнику, который отвечает один, без права перехвата остальными.

**Architecture:** Новая фаза движка `'cat-handoff'` встраивается между выбором клетки и
открытием вопроса, переиспользуя уже существующее поле `currentQuestion` и всю дальнейшую
машину (`question-open` → `buzzed` → `judging` → `reveal`) без изменений — «кот» лишь
добавляет фазу перед ней и один фильтр внутри (`catRecipientCounterId`). Онлайн-статус,
которого движок не знает (инвариант 1), проверяет `Room` до того, как событие попадёт в
движок — тем же способом, каким `Room.buzz()` уже сегодня решает `falsestart` до движка.

**Tech Stack:** TypeScript, Node, React — тот же стек, что и у остальной игры.

## Global Constraints

- Дизайн: [2026-08-12-cat-in-bag-design.md](../specs/2026-08-12-cat-in-bag-design.md).
- Открывший вопрос-«кот» не отвечает сам — обязан отдать его другому **онлайн**-участнику, не
  себе.
- Текст вопроса не виден никому, пока получатель не назначен.
- Таймер на выбор получателя — `CAT_HANDOFF_TIMER_MS = 15_000`. Истёк без выбора — получатель
  назначается случайно среди всех счётчиков партии (без фильтра по онлайн-статусу — см.
  дизайн, «Тайм-аут передачи»).
- Если в момент выбора клетки отдать вопрос физически некому (никого другого онлайн нет) —
  выбор клетки не проходит.
- Получатель отвечает один: неверный ответ или тайм-аут закрывает вопрос сразу, без
  перехвата остальными, даже при ведущем — единственное реальное изменение поведения
  `resolveVote` по сравнению с обычным вопросом.
- Верный ответ передаёт ход получателю (уже работает бесплатно через существующую логику
  `revealQuestion`); неверный/тайм-аут оставляет ход у отдавшего (тоже бесплатно).
- Генератор пакетов помечает `type: 'кот'` для 1–2 вопросов на раунд, без ограничений по цене
  или теме.

  function catJudging(
    hostId: string | null,
    counterIds: string[],
  ): EngineState {
    const state = createInitialState(CAT_PACK, counterIds, hostId);
    const handoff = selectCat(state).state;
    const recipientId = counterIds.find((id) => id !== handoff.turnCounterId)!;
    const opened = reduce(handoff, {
      type: 'assign-cat',
      counterId: handoff.turnCounterId,
      recipientCounterId: recipientId,
    }).state;
    const buzzed = reduce(opened, {
      type: 'buzz',
      counterId: recipientId,
    }).state;
    return reduce(buzzed, {
      type: 'said-answer',
      counterId: recipientId,
    }).state;

    const judging = catJudging('judge', ['p1', 'p2']);

      counterId: 'judge',

  state: EngineState,
  event: Extract<EngineEvent, { type: 'select-question' }>,

  if (state.phase !== 'selecting' || event.counterId !== state.turnCounterId) {
    return unchanged(state);
  }
  const question = findQuestion(
    state.pack,
    state.roundIndex,
    event.themeIndex,
    event.questionId,
  );
  if (!question || state.answeredQuestionIds.includes(question.id)) {
    return unchanged(state);
  }
  const currentQuestion = {
    themeIndex: event.themeIndex,
    questionId: event.questionId,
  };
  // Онлайн-статус здесь не проверяется — движок его не знает (инвариант 1).
  // «Некому отдать» отклоняет Room ДО того, как это событие сюда попадёт
  // (docs/superpowers/specs/2026-08-12-cat-in-bag-design.md, «Комната»).
  if (question.type === 'кот') {
    return {
      state: { ...state, phase: 'cat-handoff', currentQuestion },
      effects: [
        {
          type: 'start-timer',
          timer: 'cat-handoff',
          ms: CAT_HANDOFF_TIMER_MS,
        },
      ],
    };
  }
  return {
    state: { ...state, phase: 'question-open', currentQuestion },
    effects: [
      { type: 'start-timer', timer: 'question', ms: QUESTION_TIMER_MS },
    ],
  };
}

// у handleSelectQuestion выше; Room отклоняет попытку передать офлайн-

function handleAssignCat(
  state: EngineState,
  event: Extract<EngineEvent, { type: 'assign-cat' }>,
): Result {
  if (
    state.phase !== 'cat-handoff' ||
    event.counterId !== state.turnCounterId ||
    event.recipientCounterId === event.counterId ||
    !(event.recipientCounterId in state.scores)
  ) {
    return unchanged(state);
  }
  return {
    state: {
      ...state,
      phase: 'question-open',
      catRecipientCounterId: event.recipientCounterId,
    },
    effects: [
      { type: 'start-timer', timer: 'question', ms: QUESTION_TIMER_MS },
    ],
  };
}

function handleBuzz(
  state: EngineState,
  event: Extract<EngineEvent, { type: 'buzz' }>,
): Result {
  if (state.phase !== 'question-open' || !(event.counterId in state.scores)) {
    return unchanged(state);
  }
  // Вопрос-«кот»: жать может только тот, кому его передали — остальные, хоть
  // и счётчики, для этого конкретного вопроса не считаются (design.md,
  // «Правило»).
  if (
    state.catRecipientCounterId !== null &&
    event.counterId !== state.catRecipientCounterId
  ) {
    return unchanged(state);
  }
  return {
    state: { ...state, phase: 'buzzed', buzzedCounterId: event.counterId },
    effects: [
      { type: 'cancel-timer', timer: 'question' },
      { type: 'start-timer', timer: 'said-answer', ms: SAID_ANSWER_TIMER_MS },
    ],
  };
}
