# Анкеты игроков

Интересы конкретных людей — источник личных тем для генератора пакетов. Каждый раздел ниже
пишет сервер: ведущий получает от игрока код анкеты (см. `docs/anketa.html` — страница,
которую отправляют игроку, он заполняет её у себя на телефоне и присылает код обратно),
вставляет его в `/admin` → «Анкеты игроков», и сервер сам разбирает код и дописывает или
заменяет раздел этого человека. Файл можно править и руками — он для этого и человекочитаем.

Раздел одного игрока — от строки `## Имя` до следующей `## `, строки `---` или конца файла.
Игрок с тем же именем при повторной вставке заменяется целиком, а не задваивается.

Генератор пакетов читает этот файл на Шаге 0 наравне с профилем компании и собирает пакет по
правилам Шага 1 (`.claude/skills/pack-generator/SKILL.md`) — подробности и обоснования решений
в спеке: `docs/superpowers/specs/2026-08-26-player-questionnaire-design.md`.

Файл состоит из двух частей. Выше — анкеты: что человек **говорит** о себе, их пишет ведущий
(руками или через `/admin`). В конце файла сервер дописывает раздел «Показывает в игре»: что
человек **показывает** за столом, по фактам из сыгранных партий (`docs/superpowers/specs/2026-08-26-player-identity-design.md`).
Этот раздел пересчитывается целиком после каждой партии — правки руками в нём не сохранятся,
править нужно анкету выше.
